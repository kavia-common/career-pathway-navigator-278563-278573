# Career Navigator Frontend

- Save/load roadmaps via backend Roadmap APIs.
- This MVP uses a demo `user_identifier` stub (`demo-user`) for persistence scoping. This is not authentication.
- Configure REACT_APP_BACKEND_URL to point to the FastAPI server (default http://localhost:3001).
- Progress editing per skill is available in the Graph view (Not Started, In Progress, Completed) with optional percent complete and a legend.
